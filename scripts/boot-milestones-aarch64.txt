# boot-milestones-aarch64.txt — the ARM64 boot ratchet
# (scripts/boot-gate-aarch64.sh).
#
# Substrings the ARM64 kernel must print on the serial console, in this order,
# for the boot to count as unbroken. The rules are the same as the x86 list in
# boot-milestones.txt: add entries as the kernel reaches further, and never
# delete one to make CI green — a milestone that stops appearing means
# something that used to work has stopped working, which is exactly what this
# gate exists to catch.
#
# This runs on QEMU's `virt` machine, not on a Raspberry Pi. QEMU has no Pi 5
# model, so the Pi's own peripherals — RP1, SDHCI, HVS, HDMI — are proven by
# the hardware gate (home-lang/home-os#63) and can never appear here.
