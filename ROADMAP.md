# HomeOS Roadmap

HomeOS is an open-source, macOS-caliber operating system written entirely in the
[Home programming language](https://github.com/home-lang/home) — one language from
kernel to desktop — with the explicit goal of beating Omarchy on every axis.

**The full plan — phases, verifiable gates, feature-parity matrix, and risks — lives in
[`docs/MASTER_PLAN.md`](docs/MASTER_PLAN.md).**

Current phase: **Phase 0 — Truth & Toolchain** (see § 5 of the plan).
